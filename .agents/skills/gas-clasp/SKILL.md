# Google Apps Script and Clasp Workflow

This skill provides expert knowledge on managing Google Apps Script (GAS) projects using the Command Line Apps Script Projects (`clasp`) tool, alongside established GAS best practices.

## Best Practices

When writing or reviewing Google Apps Script code, always adhere to the best practices regarding performance, security, and the professional development workflow.

- See [gas-best-practices.md](references/gas-best-practices.md) for detailed guidelines on batching API calls, handling quotas, and securing scripts.

## Clasp Tool Guide

Clasp allows you to develop your Apps Script projects locally using your own tools like VS Code and git, and then push them to Google servers.

- See [clasp-guide.md](references/clasp-guide.md) for detailed instructions on installing, authenticating, cloning, developing, and deploying scripts using `clasp`.
